🎬 Movie Explorer App

A modern movie & TV series web application built with React, TypeScript, and Tailwind CSS.
The app allows users to explore trending movies, search for content, view detailed information about actors and titles, and manage session-based authentication.

## Features

.Browse movies, TV series, and trending content
.Smart search with debounce (movie / TV filter)
.Actor / People details page with biography and filmography
.Session-based authentication with countdown timer
.Modern responsive UI (mobile + desktop optimized)
.Fast data fetching with custom hooks
.Toast notifications for session expiry
.Clean component architecture

## Tech Stack

.React.js
.TypeScript
.React Router
.Tailwind CSS
.React Query (or custom fetch hook)
.Sonner (toast notifications)

## Authentication System

.Session stored using localStorage
.Auto logout after 1 hour
.Live countdown timer showing remaining session time
.Automatic redirect/logout when session expires

## Responsive Design

.Mobile-first layout
.Menu on small screens
.Full navbar on large screens
.Adaptive grid system for movies
